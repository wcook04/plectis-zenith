# Continuation-memory evidence

The six declared v1 conditions retain acquired continuation tests while matching the initial native measurement cache. The later v2 conditions transfer every acquired suffix into one ordinary held-out module, with empty target caches. Both protocols and every gain/loss are retained; these are correlated conditions over the same six archived programs, not independent tasks or production tests.

Python3.12 or later, standard library only. Unpack source.zip into a new directory. Verify the supplied evidence by rerunning acquisition, every counter, every new query, all exact certificates and all later native observations:

```sh
python3 -I verify_all.py --out run-v1
python3 -I verify_all.py --out run-v2
```

Generate new result directories, without overwriting the archived attempts:

```sh
python3 -I run_followup.py --out replay-v1
python3 -I verify_all.py --out replay-v1
python3 -I run_suffix_followup.py --out replay-v2
python3 -I verify_all.py --out replay-v2
```

The v2 driver deliberately uses the archived, verified run-v1 ordinary-module bases. These exact bases are the declared prior knowledge; no target answers or fitted target basis enter either held-out arm. Replaying v1 reproduces the same module payloads and acquisition counters.

Files: protocol.json and protocol-v2.json enumerate every condition before its original execution. run-v1/results.json and run-v2/results.json contain all costs and outcomes. Each acquisition directory retains model.json, receipt.json, certificate.json, prior-cache-binding.json, new-teacher-queries.jsonl.gz, final-cache.jsonl.gz, and later-rows.jsonl.gz. verify_all.py recomputes the acquisition, full accounting and ordered query sequence, then checks native outputs and reference identities. It writes replay-verification.json alongside a run; original verification.json and original results are preserved.

The source loader reads only the six fixed inspected programs, not arbitrary code. No inference, account access, network or credentials are involved. Verification executes additional source calls, separately from the original acquisition ledger. Exact certificates prove agreement with the declared ordinary linear reference, not arbitrary source validity.

source-manifest.json binds source/module/fixture bytes using portable paths. public_projection.json records removal of personal path metadata without changing source bytes or the original protocols. The portable driver accepts that explicit hashed metadata projection; original-driver.py preserves the original driver. source/LICENSE and source/NOTICE.md retain returned author-code licensing and source attribution; no external paper PDFs are included.
