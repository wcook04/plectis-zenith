# Failure diagnosis

**Experimental research prototype.** The public example uses synthetic observations of a disclosed toy generator. No predictive improvement has been demonstrated.

Oracle compares declared predictions with later measurements while retaining the exact earlier record. Classify unsupported evidence, incomplete coverage, disagreement, incorrect numeric prediction and execution failure separately. A missing or unavailable outcome remains unknown.

Trace a disputed claim to the first node that introduced it and inspect that node's actual inputs. Post-outcome research can explain an event but cannot become earlier evidence. An attribution is a hypothesis about a failure, not causal identification. Overlapping windows do not create independent cases.

Evolve proposes one bounded revision. Freeze it before testing original and revised graphs on matched held-out later cases with the same targets, model and budget. Record regressions, uncertainty, failures and costs beside gains. Valid JSON or a plausible diagnosis is not improved prediction.
