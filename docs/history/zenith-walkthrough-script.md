# Zenith walkthrough

Historical research record. References to “current” or “next” describe this stage; see [today’s findings](../status.md).

Zenith asks whether a reasoning graph can improve by examining its own failures. Several feeds describe one system before a cutoff. The Lab reads them, saves each reasoning step and freezes predictions of named observables at a declared horizon.

The public example is an invented abstract System A. Measurements, subsystems, environment, events and interventions are five synthetic perspectives of one generated state. A sixth feed computes summaries. This is a teaching example, not a physically validated simulation.

Later observations go to Oracle beside the frozen Lab record. Oracle measures differences and proposes a hypothesis about what went wrong. Evolve proposes one change. We then compare the original and revised graph on further matched cases with the score and budget fixed before opening their outcomes.

The current preparation loads inputs and writes the first request. It makes no model call and produces no completed forecast. No predictive improvement has been demonstrated.

A proposed controller could use variability, missingness, disagreement and event density available at the cutoff to choose small prompt variations. Its numbers index written wording. They are distinct from learned controller parameters. That extension has not been implemented or tested.

Think of different physics problems. In a heated chamber, temperature sensors, heater power and door logs could support a temperature prediction six hours ahead. With a vibrating system, a camera gives position and an accelerometer gives another part of the motion. We need the history and force records too, because one position does not tell us the direction. Flow, pressure, dye and valve observations could support a fluid concentration target, with the geometry and boundaries supplied.

The proposed graph would align the clocks and units, check which sources repeat each other, compare a faulty sensor with a change in the system, and choose a physical model or numerical tool where one is available. It would freeze the target, horizon and uncertainty. That integration has not been built or tested. The words are not replacing equations, and the synthetic System A example is still just a protocol fixture. History can help without making every hidden state identifiable.
