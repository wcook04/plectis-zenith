# Status

The original Lab/Oracle/Evolve loop runs. Reviewed changes can affect the next
day, and matched later comparisons can retain or reject a candidate. Forecast
and selection scorers keep the full declared denominator.

No tested version has established a forecasting advantage. Earlier studies and
negative results are preserved in Git history and the private Type B archive.
They are not evidence that the original multi-feed vision fails: recent inputs
were substantially narrower than the original system's.

The next task is a small, audited historical multi-feed snapshot, then a run of
the existing graph on that evidence. The FNSPID source adapter remains as the
starting data path. See [data coverage](feed-coverage.md).

At the author's request, the working repo now omits alternative benchmark
programmes, the fitted-head experiment, UI/API scaffolding, the formal demo,
vendor skill copies and long research surveys. The paper is limited to three
pages. The retained source and original materials are preserved separately so
simplicity does not erase what was tried.
