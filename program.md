# Zenith research programme

**Experimental research prototype.** The public example uses synthetic observations of a disclosed toy generator. No predictive improvement has been demonstrated.

Keep the original idea: earlier observations from several feeds → Lab predictions → later Oracle evaluation → one reviewed Evolve revision → held-out matched comparison.

Use an invented abstract System A for the public example. Five synthetic source perspectives describe measurements, subsystems, environment, events and interventions; the sixth derives summaries from the supplied observations. The architecture can receive observations of other dynamical systems, but this example establishes no universal scientific capability.

Freeze the target universe, horizon, score, model, graph and work budget before revealing outcomes. Keep development cases separate from later comparison cases. Valid intermediate records are execution evidence, not improved prediction. The context-conditioned prompt controller remains a proposal.
