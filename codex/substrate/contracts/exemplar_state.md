# Exemplar State Contract v1.0

## Purpose
Defines the format for the **ideal state** a node *should have* produced given the actual market outcome. Generated by audit post-mortem nodes after truth data is available.

## Schema

```
EXEMPLAR_STATE:
  horizon: <resolved horizon label>
  truth_timestamp: <ISO UTC>
  node_id: <string>
  lane: <string>

VECTORS:
  - original: <original prediction vector line>
    exemplar: <what the vector SHOULD have been given truth>
    delta: <directional error: CORRECT | OVERSHOOT | UNDERSHOOT | WRONG_DIRECTION>
    magnitude: <numeric deviation from truth, e.g. "SPY off by 1.2%">

SCORE:
  hit_rate: <fraction of vectors directionally correct>
  band_capture: <fraction of actual values within predicted bands>
  confidence_calibration: <HIGH predictions correct % | MEDIUM | LOW>

LESSONS:
  - <one-line actionable insight per vector miss>
```

## Rules
1. Every prediction vector from the original run MUST have an exemplar counterpart
2. `delta` classification is mandatory — no "N/A" or "unclear"
3. Truth data source MUST be cited (run ID or feed)
4. If original data was C:LOW and prediction was wrong: note "C:LOW correctly flagged" or "C:LOW warning ignored"
