# Contributing

Read README.md, program.md and AGENTS.md. Tie changes to executable
investigations, measured program repair or useful reuse. Preserve source
identity, failed attempts and the ordinary-code, fixed-test and repair-only
controls. Freeze selection before later evaluation; keep historical graph
experiments separate from the current native and client studies.

Install `.[test]`, run `make validate` and `make test`, then commit only the
intended files. Keep provider keys, private snapshots and private observation
payloads out of Git. Publish experiment records through their allowlisted
exporters and check archived replay from a fresh checkout. Cite external
methods and data where used. Frontend changes also need `npm test` and
`npm run build` in `site/`, followed by desktop and mobile inspection.
