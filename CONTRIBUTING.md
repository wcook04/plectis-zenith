# Contributing

Read README.md, program.md and AGENTS.md. Keep changes tied to the daily
Lab → Oracle → Evolve loop. Preserve source clocks, failed attempts and the
original graph baseline. Do not claim improvement without a later comparison.

Install `.[test]`, run `make validate` and `make test`, then commit only the
intended files. Keep provider keys, private snapshots and acquired article
bodies out of Git. Cite external methods and data where used.
