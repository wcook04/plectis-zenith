# Security

This is a research prototype. Keep credentials, private feeds, transport records
and unpublished provider responses out of Git. Reviewed public experiment
bundles use allowlisted exports. Provider execution is explicit and can incur
costs; the public reading website cannot execute models or expose local runs.
Keep frozen spending limits and any explicit funding amendments auditable.

Report vulnerabilities privately to the maintainer through the channel that
supplied this checkout. Include a source revision and a minimal synthetic
reproduction, without credentials or private data. Generated programs run under
research-specific restrictions; the executor is not a general sandbox service.
